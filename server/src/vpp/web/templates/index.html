{{ _("How the buzz works") }}

  1. {{ _("Pay straight to the recipient") }}

    {% trans %}Checkout runs on Stripe, and the money goes into the recipient's own account. We never touch it.{% endtrans %}

  2. {{ _("Everyone sees the same ledger") }}

    {% trans %}Each payment is signed and added to a public ledger. Outside witnesses check that nobody rewrites it, and you get a receipt to keep.{% endtrans %}

  3. {{ _("The recipient signs for it") }}

    {% trans %}They tap a passkey tied to their own website. Payments they've signed for show as confirmed. The rest show as recorded.{% endtrans %}

{{ _("Where Bitcoin comes in (and where it doesn't)") }}

{% trans %}Donations here are ordinary card payments in euros, through Stripe. Nobody buys, sells, holds or sends bitcoin. There's no wallet, no coin and no token, and the money never goes near a blockchain.{% endtrans %}

{{ _("We only borrow Bitcoin's clock. Once an hour:") }}

  1. {% trans %}We take the ledger's latest signed checkpoint and compute its fingerprint, a SHA-256 hash. It's 64 characters that say nothing about who paid whom.{% endtrans %}
  2. {% trans %}We send that fingerprint, mixed with a random value, to OpenTimestamps, a free public service. It bundles fingerprints from many people into a single Bitcoin transaction and pays the small fee itself. We pay nothing.{% endtrans %}
  3. {% trans %}Within a few hours that transaction is in a Bitcoin block. From then on anyone can prove the checkpoint existed by that time, and nobody, us included, can backdate the ledger or quietly swap in a different history.{% endtrans %}

{% set repo %}{% if anchors_url() %}{{ _("git repo") }}{% else %}{{ _("git repo") }}{% endif %}{% endset %}{% trans repo=repo %}No payment details, names or amounts go to Bitcoin or to OpenTimestamps, only the fingerprint. The checkpoints and their proofs are also kept in a public {{ repo }} where rewriting history is switched off. The verifier checks each proof against Bitcoin by itself, using your own Bitcoin node or, if you don't run one, the public explorer mempool.space.{% endtrans %}
